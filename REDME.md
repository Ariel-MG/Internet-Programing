## 📋 Descripción del Proyecto

Este repositorio contiene el desarrollo completo del curso de **Programación para Internet**, incluyendo prácticas individuales, proyectos de medio término, exámenes y un sistema web integrado con navegación unificada.

El proyecto implementa tecnologías web modernas con enfoque en **HTML5**, **CSS3**, **JavaScript**, **PHP**, y **MySQL**, desarrollando desde páginas estáticas hasta aplicaciones web dinámicas con contenedores Docker.

## 🏃‍♂️ Instrucciones de Uso

### 📋 **Requisitos Previos**
- Navegador web moderno (Chrome, Firefox, Safari, Edge)
- Servidor web local (opcional para desarrollo)
- Docker y Docker Compose (para Práctica 7)

### 🖥️ **Ejecución Local**

1. **Clonar el repositorio:**
```bash
git clone https://github.com/Ariel-MG/Internet-Programing.git
cd Internet-Programing
```

2. **Abrir página principal:**
```bash
# Navegar a la página principal
open MT/P1/index.html
# O usar servidor local
python -m http.server 8000
```

3. **Ejecutar Práctica 7 (Docker):**
```bash
cd MT/P1/paginas/practica7
docker-compose up -d
```

4. **Convertidor Universal:**
```bash
# Acceder directamente
open MT/P2/P2.html
```
